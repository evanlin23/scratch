# SIMHIGH_R47, SIMHIGH_R48: vote-model replicates (helper p47)

AliSim replicates generated by `cs581/gcmtrees/code/gen.sh` (seeds 100r+7, 100r+13), one MAGUS draw (paper flags)
via `cs581/gcmtrees/code/run.sh SIMHIGH_Rk`, plus `gg.py run REP 'linsi#es4'`. Same procedure as results_t20.

- `magus.jsonl`: MAGUS end-to-end row (bbtool_bench).
- `aln.jsonl`: gg.py rows (`variant` linsi, recipe = wsoft0.03:linsi&fftns2#es4, linsi#es3, linsi&fftns2-op3,
  linsi#es4; no `B` key) followed by vote.py rows from `cs581/gcmvote/code/run.py` (`B` = 10; magus, hard,
  hard-bb, soft4). FastSP against the true alignment.
- `trees.jsonl`: protbench trees.py rows (FastTree -lg -gamma, nRF = `RF` vs the true tree). Methods `true`,
  `magus` (gg linsi), `es4`, `recipe`, `vote_hard`, `vote_hard-bb`.

Vote rep dir: /opt/work/gcmvote/reps/SIMHIGH_Rk with `inputs` and `true.fasta` symlinked from the gcmtrees rep.

Checks: vote.py `magus` equals gg.py `linsi` (MAGUS's merge) up to row order (`scripts/norm.py`, same hash) with
identical SPFN/SPFP/TC.

`scripts/`: `rep.sh` (whole per-replicate lane, trees 4 at a time via xargs -P 4), `finish.sh` (bank + rows).
