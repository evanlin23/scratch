# Consensus-MSA significance test

Inputs are the MAGUS paper's published alignments of each replicate; the consensus is `gcmx.consensus` (fixed design: most-central input as primary, ~13-sequence similarity groups, all inputs as GCM evidence). Error = (SPFN+SPFP)/2 in %.

_225 of the 228 planned replicates finished in each scenario; 1000L1/R10, 1000L3/R10 and BAliBASE RV100_BBA0067 did not complete on the workers._
