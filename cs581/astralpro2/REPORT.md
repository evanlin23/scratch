## 1. Theory summary (details and proofs in `theory.md`)

**Model R.** All results are on the 4-taxon caterpillar (((A,B)x,C)y,D) under pure GDL with branch-specific rates:
- branch x has no events;
- the tip branches enter only through the per-copy survival probabilities a, b and c;
- the y-branch can be any birth–death process.

**Results.**

| result | statement | status |
|---|---|---|
| Lemma 1 | With the correct root, SQ classes correspond to S-tagged nodes w of the ABC part whose children split {A,B,C} as 2\|1 | proof |
| **Thm 1** | Exact limiting ASTRAL-Pro scores with the correct root and ASTRAL-Pro's species-overlap tags: correct = E[N_y]·abc + E Σ_w V_AB(i_w,j_w); wrong = E Σ_w V_AC (or V_BC) | proof |
| **Thm 2** | Per duplication node with unequal copy numbers i ≠ j on its two sides: V_AB − V_AC = (ā^j − ā^i)·g_B·g_C·(r_B − r_C), so **sign = sign(b − c)** (and sign(a − c) for AD\|BC) | proof |
| Cor 1 | If c ≤ min(a, b), overlap tagging is consistent for *every* y-branch process, and also under any random hidden-paralog mislabelling | proof |
| **Thm 3** | Pure-birth y-branch with λT = ln 20, a = b = 1/100, c = 1/5: limiting scores per y-copy are correct 2.4025e-4 vs 3.2663e-4 for each wrong topology (50-digit interval arithmetic). **ASTRAL-Pro with correct root + its own tagging rule is statistically inconsistent.** The mislabelling threshold is q* = 0.188 | proof, computer-assisted with closed form + interval arithmetic |
| Prop 4 | Stock ASTRAL-Pro3 rooting (min D/L score, random tie-break) in the Thm 3 setting: correct − AC\|BD = **−0.00487 ± 0.00004 per family** (z = −117), 2.6× worse than the correct root (−0.00184 ± 0.00005) | statistical certificate, not a proof; `apro.py` re-implementation validated against the binary |
| **Prop 5** | Tags from LCA reconciliation against *any* species tree T make every SQ display T, so ASTRAL-Pro returns T. "Re-root/re-tag against a first-pass tree" therefore just returns the first-pass tree | proof |

**Mechanism in one sentence.** At a y-branch duplication whose two sides carry unequal numbers of copies, the larger side is more likely to contain every species. That inflates the hidden-paralog patterns that pair the best-surviving outer taxon C with a cherry taxon, and the worse survivor of A and B is pulled toward the outgroup.

**What is new compared with gdlcons.**
- gdlcons had numerical counterexamples.
- Here there is a closed form, a sign law with a sufficient condition for consistency, a rigorous instance, and the reconciliation fixed-point observation.

### 2c. Published-style rates (`results/realscan.jsonl`, exact formula, correct root + overlap tags)

**Setup.**
- Induced caterpillar quartets from 26-taxon ultrametric Yule trees with height 1 (40 trees), with D drawn from the other side of the root.
- λH on a grid; μ = rλ with r ∈ {0, 0.5, 1, 2}.
- Optional per-branch log-normal rate multipliers (σ).

**Reference values.** The ASTRAL-Pro / DISCO S25 default is λ = μ = 4.9·10⁻¹⁰ per generation and height ≈ 1.9·10⁹ generations, so **λH ≈ 0.93, r = 1, σ = 0**. The ASTRAL-Pro grid goes up to λ⁺ = 5·10⁻¹⁰ (λH ≤ ~1).

| λH | σ = 0 | σ = 0.5 | σ = 1 |
|---|---|---|---|
| 0.25–1 | 0 / 4,800 failing (min margin 0.74 at λH = 1) | 0 / 4,800 | 0 / 4,798 |
| 2 | 0 / 1,600 (min 0.43) | 0 / 1,600 | 0 / 1,585 (min 0.13) |
| 4 | 0 / 1,600 (min 0.17) | 0 / 1,596 (min 0.02) | **3 / 1,499** |
| 8 | 0 / 1,600 | 0 / 1,515 | **2 / 1,346** |
| 16 | 0 / 1,315 | **4 / 1,328** | **5 / 1,171** |

**Reading the table.**
- With the correct root, failures need **4× or more the published duplication load *and* strong per-branch rate heterogeneity** (σ = 1, i.e. rates varying about 3× between branches), and even then they occur in only 0.2–0.4% of quartets.
- At published rates (λH ≤ 1, homogeneous rates) there are none, and the minimum margin is 0.74.

**Stock rooting at S25-like rates** (`results/realown.jsonl`, full 26-taxon gene trees, 2,000 families, 30 quartets × 3 trees per setting):

| setting | quartets | true tags: neg / min | correct root + ovl: neg / min | **stock own**: neg / min (median) |
|---|---|---|---|---|
| S25 default (λH = 0.93, homogeneous) | 90 | 0 / 1.00 | 0 / 0.97 | 0 / 0.87 (0.99) |
| 4× load (λH = 4, homogeneous) | 90 | 0 / 1.00 | 0 / 0.39 | 0 / 0.21 (0.96) |
| λH = 2, per-branch σ = 1 | 79 | 0 / 1.00 | 0 / 0.00 | 0 / 0.00 (1.00) |
| λH = 4, per-branch σ = 1 | 39 | 0 / 1.00 | 1 / -1.00 | 1 / -1.00 (1.00) |

**Readout.**
- At the published S25 setting, stock rooting is safe: no quartet has a negative margin, the minimum is 0.87 and the median 0.99.
- At 4× load, stock rooting lowers the worst margin from 0.39 to 0.21.
- The single negative quartet (σ = 1, λH = 4) has zero orthologous support under true tags: its entire ASTRAL-Pro score comes from hidden paralogs. That is the Theorem 3 mechanism, but on a quartet with negligible weight.

**Readout.**
- **Inherit the failure:**
  - stock ASTRAL-Pro3;
  - ASTRAL-Pro with the correct root (`ovl`);
  - DISCO + ASTRAL;
  - **wQFM-GDL**. Its SQ weights come from DISCO's ASTRAL-Pro-style rooting and tagging, which is confirmed in `wQFM-GDL.sh`.
  - Duplication-only gene-tree parsimony (`gtp_dup`, i.e. DupTree's criterion).
- **Reconciliation retagging against a first-pass tree** (`recon_first`) keeps the wrong first-pass tree, exactly as Prop 5 predicts. Retagging against the true tree is right, but it is an oracle.
- **Robust here:**
  - duplication + loss parsimony (`gtp_dl`, and **DupLoss-2**). The loss term penalises the hidden-paralog explanation.
  - In R1/R2, **ASTRAL-multi** is at a three-way near tie: ASTRAL-multi score correct − best wrong = −0.10 ± 0.08 per family on R1 and −0.33 ± 0.16 on R2 (20 blocks, `multiq.py`). That is not significant, and the same holds for ASTRAL-ONE (−0.003 ± 0.003). Its block-level errors are sampling noise around a tie, not evidence against Legried et al. (who state their proof does not need constant rates). On cand4 it is right.
- **SpeciesRax** was not run. GeneRax installed from bioconda, but SpeciesRax needs per-family alignments and a model, and I ran out of budget. It is reconciliation-likelihood based (UndatedDL), so by analogy with `gtp_dl` I would expect it to be robust [M, untested].

## 4. Estimated gene trees (task 4; `code/est.py`)

**Pipeline.**
- Families simulated with branch lengths (`gdl_len.py`).
- Sequences from AliSim: GTR+G4, 400 bp, tree height 0.6 subs/site.
- Gene trees estimated with FastTree -gtr.
- 1,000 genes per replicate.
- Settings:
  - **S25**: 26 taxa, λ = μ = 0.93/H;
  - **S25het**: λH = μH = 2 with per-branch σ = 1;
  - **Rown**: 4 taxa, model R with a = b = 0.02, c = 0.6, λT = 2. This is a cell where the correct root is consistent (+0.13) but stock rooting is not (−0.15).

| setting | gene trees | ASTRAL-Pro3 wrong | DISCO+ASTRAL wrong | ASTRAL-multi wrong |
|---|---|---|---|---|
| **Rown** (4 taxa) | true | **5/5** | 5/5 | 2/5 |
| **Rown** (4 taxa) | FastTree estimates | **5/5** | 0/5 | 2/5 |
| S25 (26 taxa, rep 0) | true | FN 0 | FN 0 | FN 0 |
| S25 (26 taxa, rep 0) | FastTree estimates | FN 0 | FN 0 | FN 0 |

**Readout.**
- **The effect survives gene-tree estimation.** In the failure cell, stock ASTRAL-Pro3 returns the wrong tree on 5/5 estimated-tree replicates of 1,000 genes.
- DISCO+ASTRAL becomes right on estimated trees. My guess [unverified] is that estimation error breaks up the hidden-paralog patterns that DISCO's decomposition keeps.
- ASTRAL-multi sits near a tie here too.
- At the published S25 setting, all methods recover the tree, on true and on estimated trees.
- S25 reps 1–2 and S25het were cut by the time budget (the pipeline in `run_est.sh` is restartable).

## 6. Proposed 4-week project

**Title idea:** "ASTRAL-Pro is not statistically consistent under GDL: an exact characterization of hidden-paralogy and rooting bias."

| week | work |
|---|---|
| 1 | Clean up and generalise the theorems: drop "no events on x" via a positive-association argument for x (x events help the correct topology, Section 3 of `theory.md`); n-taxon statement via induced quartets; write the proofs |
| 2 | Min-score rooting: either an exact formula in model R (the true root is optimal in 97% of families, so a perturbative expansion is plausible) or a provable bound. Then a theorem that stock ASTRAL-Pro is inconsistent |
| 3 | Practice: realistic-rate prevalence (correct root and own rooting), estimated gene trees, and the method table (ASTRAL-Pro, DISCO, wQFM-GDL, ASTRAL-multi, DupLoss-2, SpeciesRax). Optionally a fix: a branch-length/dating-aware tagger, or a loss-aware (D+L reconciliation) rooting |
| 4 | Write-up and figures (phase diagrams, sign law) |

**Risks.**
- (i) **Practical relevance is low at published rates.** No failures appear at λH ≤ 2 or with homogeneous rates; it needs heavy loss on two lineages and ≥ 4 copies entering an internal node. The project must be pitched as *theory* (answering slide-35 question 1 negatively, with a sharp sign law) rather than "ASTRAL-Pro is wrong on real data".
- (ii) A rigorous result for stock min-score rooting may not close in 4 weeks. The fallback is the statistical certificate plus the correct-root theorem.
- (iii) Parsons et al. 2026 (bioRxiv, DLCOAL tagging) was still unread in full. Check overlap before submitting.
- (iv) If the ASTRAL-multi near tie turns out to tip the wrong way under branch-specific rates, that would contradict Legried et al.'s remark that their proof does not use constant rates. That would be big if true, but it is unverified here (difference not significant).
