                     Notes
• Each proﬁle generates strings of exactly the
  same length. This is not very useful for dealing
  with biological data.

• If you are given a sequence that is generated
  by the proﬁle, then you know exactly what
  path was used to generate the sequence. That
  is, none of the states are hidden.
  Inser)ons and Dele)ons (Indels)
• Inser)ons: events that increase the sequence
  length, such as:
  – AAAAA -> AATCGAAA
  – AAAAA -> AAAAATCGATTA
• Dele)ons: events that decrease the sequence
  length, such as:
  – ATCGA -> AGA
  – AAAAA -> AA
      Allowing for sequence length
             heterogeneity
• The proﬁle shown in the previous slides only

  doesn’t allow any inser)ons or dele)ons.
• To model indels, we just have to add
  addi)onal states to the graphical model.
  – Inser)on states: Diamonds (have non-zero

  – Dele)on states: Circles (nothing emiYed)

               Hidden states
• For some sequences, there is no path through
  the proﬁle HMM that can generate the sequence.
• For some other sequences, there is exactly one
  path.
• And then for some others, there is more than one
  path… and you can’t tell which one generated the
  sequence! More generally, you can’t tell which
  state generated each leYer in the sequence – so
  the states are said to be “hidden”.
