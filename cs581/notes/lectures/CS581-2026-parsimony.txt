                 Bipartitions
• Bipartitions are defined by edge deletions in
  unrooted trees. The set of bipartitions for tree
  T is denoted by C(T).
• Example: If T= (A,(B,(C,(D,E)))), then C(T) is
  – AB|CDE
  – ABC|DE
• A set X of bipartitions is “compatible” if there
  is a tree T such that C(T) contains X.

  1. Given set X of bipartitions on leafset S, is the set X
     compatible?
  2. Given X, produce the tree T such that C(T)=X (or say
     no such tree exists)

  – Recall how to test compatibility of clades.

Is Maximum Parsimony statistically
     consistent under CFN?
• Recall the CFN model of binary sequence
  evolution: iid site evolution, and each site
  changes with probability p(e) on edge e,
  with 0 < p(e) < 0.5.
• Is MP statistically consistent under this
  model?
   Statistical consistency under CFN

• We will say that a method M is statistically
  consistent under the CFN model if:
  – For all CFN model trees (T,Θ) (where Θ
    denotes the set of substitution probabilities on
    each of the branches of the tree T), as the
    number L of sites goes to infinity, the
    probability that M(S)=T converges to 1, where
    S is a set of sequences of length L.

   Uninformative Site Patterns
Uninformative site patterns are ones that fit
every tree equally well. Note that any site
that is constant (same value for A,B,C,D) or
splits 3/1 is parsimony uninformative.

On the other hand, all sites that split 2/2 are
parsimony informative!
  Parsimony Informative Sites
• [A=B=0, C=D=1] or [A=B=1, C=D=0]
  – These sites support ((A,B),(C,D))


• [A=C=1, B=D=0] or [A=C=0, B=D=1]
  – These sites support ((A,C),(B,D))


• [A=D=0,B=C=1] or [A=D=1, B=C=0]
  – These sites support ((A,D),(B,C))
       Calculating which tree MP picks
When the input has only four sequences, calculating what MP does is
easy!

1. Remove the parsimony uninformative sites
2. Let I be the number of sites that support ((A,B),(C,D))
3. Let J be the number of sites that support ((A,C),(B,D))
4. Let K be the number of sites that support ((A,D),(B,C))
5. Whichever tree is supported by the largest number of sites, return
   that tree. (For example, if I >max{J,K}, then return ((A,B),(C,D).)
6. If there is a tie, return all trees supported by the largest number of
   sites.

 Sankoff’s DP algorithm for MP
Input: a given rooted binary tree T and a single
  character (site in an alignment), and maybe a
  substitution weight matrix
Output: the best achievable MP cost, and (if
 desired) a labelling achieving that MP cost
This algorithm can be used to solve maximum
  parsimony (MP) for weighted or unweighted
  cases.
To do this for an entire alignment, you just do it for
  each site at a time.
         Sankoff DP algorithm
Two phases:
• The first phase (bottom-up) finds the best
  score.
• The second phase (top-down) assigns labels
  (states) to each node (using the usual back-
  tracking approach in dynamic programming)
We will focus on describing phase 1 (bottom-
up): we root the tree arbitrarily.
          Sankoff DP algorithm
• Assume T is rooted and we are looking at a single
  site
• Cost(u,x) is the best parsimony score achievable
  for the clade rooted at u, given that we label u by
  state x.
• Base cases: Cost(u,x) for u a leaf (think infinite
  cost and 0 cost)
• What we want: Cost(root,x) for each possible
  state x. Then we take the minimum across all x.

           Summary (updated)
• Maximum Parsimony (MP) is statistically consistent on
  some CFN model trees.
• However, there are some other CFN model trees in
  which MP is not statistically consistent. Worse, MP is
  positively misleading on some CFN model trees. This
  phenomenon is called “long branch attraction”, and the
  trees for which MP is not consistent are referred to as
  “Felsenstein Zone trees” (after the paper by
  Felsenstein).
• The problem is not limited to 4-leaf trees…
                  Characters
• A character is a function c: S -> Z, where S is the
  set of leaves and Z is the set of possible states
  (could be integers, could be nucleotides, etc.)
• The sites in an DNA alignment can be characters,
  in which case the states are nucleotides
• Presence/absence of a property can be a
  character (with 0 representing absence, 1
  representing presence)
                   Homoplasy
• Homoplasy means back-mutation or parallel evolution
• We say a character evolves with homoplasy on a tree if
  it used back-mutation or parallel evolution
• Wings (presence or absence) is a homoplastic character
• Homoplasy-free characters are ones that evolve
  without homoplasy on a tree
• A character c is said to be “compatible” with (or on) a
  tree T if you can demonstrate that c evolves without
  homoplasy on T (by showing states at internal nodes).
• You may be asked: is this character compatible on T?

              Strict Consensus
• We are given a profile of trees {T1 , T2 ,T3 … Tk}

• The Strict Consensus is the (unique) tree T so
  that C(T) is the intersection of C(Ti) over all I
• Thus, the strict consensus has all the
  bipartitions that appear in every tree in the
  profile
           Majority Consensus
• We are given a profile of trees

• The majority consensus has all the bipartitions
  that appear in strictly more than half of the
  trees in the profile
              Greedy Consensus

• The greedy consensus is defined algorithmically!
• Order the bipartitions by the frequency in the
  profile, most frequent to least frequent
• Start with a star tree
• Process each character in turn:
   – Add it to the previous tree, if it is compatible –
     otherwise discard
• Return the tree after all characters are processed
