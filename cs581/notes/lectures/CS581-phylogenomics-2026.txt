                         Class Exercise
Let T be a model rooted MSC species tree with topology (A,(B,(C,D))) and
probability of coalescence on each edge in (0,1).

1.   Suppose a gene evolves within T under the MSC (Multi-species coalescent)
     model, but without any deep coalescence. What does its rooted tree look
     like? What is the unrooted tree topology?
2.   Suppose a gene evolves within T under the MSC, and there is a coalescence
     on the edge above the LCA of C,D.
         1. What are the possible rooted trees for this gene?
         2. What are the possible unrooted trees?
3.   Suppose a gene evolves within T under the MSC, and there is no coalescence
     on the edge above the LCA of C,D but there is one on the edge above the
     LCA of B,C,D. What is the probability of each of the three gene trees?
4.   Suppose a gene evolves within T and there are no coalescences below the
     root. What is the probability of each unrooted gene tree?
5.   Overall, what unrooted tree topology has the highest probability?

Theorem (Allman et al.): Under the multi-species coalescent
model, for any four taxa A, B, C, and D, the most probable
unrooted gene tree on {A,B,C,D} is identical to the unrooted
species tree induced on {A,B,C,D}.

unrooted species tree is identifiable from the distribution on
unrooted gene trees.

Proof: For every four species, select most frequently
observed tree as the species tree. Then combine quartet
trees!

       ASTRAL solves the Constrained
       Maximum Quartet Support Tree
• Input: Set T = {t1,t2,…,tk} of unrooted gene trees, with each tree on set S
  with n species, and set X of allowed bipartitions
• Output: Unrooted tree T on leafset S, maximizing the total quartet tree
  similarity to T, subject to T drawing its bipartitions from X.

Theorems (Mirarab et al., 2014):
• If X contains the bipartitions from the input gene trees (and perhaps
   others), then an exact solution to this problem is statistically consistent
   under the MSC.
• The constrained MQST problem can be solved in O(|X|2nk) time. (We use
   dynamic programming, and build the unrooted tree from the bottom-up,
   based on “allowed clades” – halves of the allowed bipartitions.)

Conjecture: MQST is NP-hard

         Default vs Exact ASTRAL
• ASTRAL solves this Constrained Maximum
  Quartet Support Tree, which assumes a set X of
  allowed bipartitions is provided

• Default ASTRAL: X is all bipartitions from the
  input gene trees

• Exact ASTRAL: X is all possible bipartitions
