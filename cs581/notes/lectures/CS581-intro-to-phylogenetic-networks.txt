                       Phylogenomic pipeline
• Select taxon set and markers
• Gather and screen sequence data, possibly identify orthologs
• Estimate multiple sequence alignments for each locus, and estimate gene trees
• Estimate species tree or phylogenetic network:
   • Combine the estimated gene trees, OR
   • Estimate a tree from a concatenation of the multiple sequence alignments
• Get statistical support on each branch (e.g., bootstrapping)
• Estimate dates on the nodes of the phylogeny
• Use species tree with branch support and dates to understand biology
Phylogenetics: Statistical Estimation Problem
• A statistical model of evolution is provided (high-level, without
  numeric parameter values): e.g., Jukes-Cantor
• Then,
   • given the data (sequences at the leaves of the true, but unknown,
     phylogeny,
   • we seek the phylogeny that best fits the data

Markov Models of Sequence Evolution
The different sites are assumed to evolve i.i.d. down the model tree

Simplest site evolution model (Jukes-Cantor, 1969):
• The model tree T is binary and has substitution probabilities p(e) on each edge e, with 0<p(e)<3/4.
• The state at the root is randomly drawn from {A,C,T,G} (nucleotides)
• If a site (position) changes on an edge, it changes with equal probability to each of the remaining
  states.
• The evolutionary process is Markovian.


More complex models (such as the Generalized Time Reversible model) are also considered, often
 with little change to the theory.

Estimating gene trees: difficult but doable!
• Assuming standard DNA evolution models (e.g., Generalized Time
  Reversible model)
• Estimating gene trees (phylogenetic trees for single genes)
  • Most good approaches are NP-hard (e.g., maximum likelihood) but
    statistically consistent (error goes to zero as data goes to infinity)
  • Good heuristics are available, so large trees (thousands of leaves) can be
    estimated with good accuracy in a few minutes to several hours or days

 Species tree estimation from
 unrooted gene trees

Theorem (Allman et al.): Under the multi-species coalescent
model, for any four taxa A, B, C, and D, the most probable
unrooted gene tree on {A,B,C,D} is identical to the unrooted
species tree induced on {A,B,C,D}.
 Species tree estimation from
 unrooted gene trees

Corollary: Under the multi-species coalescent model, the
unrooted species tree is identifiable from the distribution on
unrooted gene trees.

Proof: For every four species, select most frequently
observed tree as the species tree. Then combine quartet
trees!

        From: Elworth, RA Leo, et al. arXiv arXiv:1808.08662.
Two problems under the Network Multi-
Species Coalescent (NMSC) model
• Problem 1: Given a set of rooted gene trees, find a rooted
  phylogenetic network that best fits the input
• Problem 2: Given a set of rooted gene trees and a rooted species
  tree T, add edges to T to produce a rooted phylogenetic network
  that best fits the input

Note: these problems are often restricted to level-1 phylogenetic
networks, since level-2 phylogenetic networks are not identifiable
Methods
• PhyloNet (Luay Nakhleh et al.): several tools
   • Codes for maximum pseudo-likelihood (MPL), maximum parsimony, and
     maximum likelihood
   • MPL is preferred due to better scalability than maximum likelihood and
     statistical consistency
   • Not limited to level-1 networks
• SNaQ (Solis-Lemus et al.):
   • Code for MPL, restricted to level-1 networks
• And others that are less frequently used in biological studies
• Plus CAMUS (Willson and Warnow, 2026)
Some mathematical results
• Some of the algorithms developed for level-1 phylogenetic
  network estimation are based on quartet trees.
• Some strong mathematical properties have been established, but
  typically are about identifiability rather than estimation given finite
  and imperfect data! See for example work by
   • Elizabeth Allman, Cécile Ané, Hector Baños, Philippe Gambette,
     Katharine Huber, Steven Kelk, Erin Molloy, Vincent Moulton, John Rhodes,

• CUPNS: statistically consistent polynomial time method for
  estimating a level-1 phylogenetic network from SNPs
• CUPNS is based on being able to infer the quartet trees in
  Q(Nr)
CUPNS: pros and cons
• Statistically consistent, polynomial time
• But: will fail to return a network when the technique used to infer the quartet
  trees from Q(Nr) has any mistakes

• This restriction is true of many other theoretically-focused methods

• Hence: We need a method that can reconstruct a good estimate of the level-1
  phylogenetic network that is robust to this failure
CAMUS (Willson and Warnow 2026)
Consider this problem:
• Input: a rooted tree T and a set Q of quartet trees
• Output: A level-1 phylogenetic network N built on T that satisfies as many
  quartet trees in Q as possible


CAMUS solves this in polynomial time (using dynamic programming)/

A variant of CAMUS can solve the restricted problem of finding the best level-1
network with at most a given number of reticulations


Published in Bioinformatics 2026, special issue for ISMB 2026
Using CAMUS in a pipeline
Given a set of rooted gene trees (from across the genomes):
1. Estimate the rooted species tree T (e.g., using ASTRAL)
2. Extract all (unrooted) quartet trees from the gene trees
3. Restrict to a subset Q* of the quartet trees, based on a
   statistical test (accounting for ILS) and a threshold t, 0<t<1
4. Apply CAMUS to (T,Q*), obtaining level-1 network N built on T

Filtering quartet trees
• Recall: In a level-1 phylogenetic network, there are at most two
  quartet trees for any four species.
• If we know exactly which quartet trees are available for every four
  species, we can construct the level-1 network.
• Therefore: a key step in the CAMUS pipeline is restricting the set of
  quartet trees for a given set of four species, to either 1 or 2 trees

Summary and Future Work
• Summary:
  • CAMUS is fast, can scale at least to 200 species, and has better accuracy
    compared to PhyloNet-MPL(FT)
  • For smaller numbers of species, methods that do not fix the tree (i.e.,
    SNaQ and PhyloNet-MPL ) are slightly more accurate
  • CAMUS and SNaQ are limited to constructing level-1 networks
  • No guarantees of statistical consistency, even if the true network is level-1
• Future work
  • Improve scalability to more than 200 species
  • Develop other techniques to estimate the underlying tree T
  • Extend technique to estimate more complex networks
