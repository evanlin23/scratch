## Instructor's open problems ("possible course projects", first-day slides)

* Multiple sequence alignment: merging two alignments; consensus alignments
* Supertree estimation: scale to 100,000+ species with high accuracy; approximation algorithms
* Species tree and phylogenetic network estimation: gene tree heterogeneity from multiple causes
  (incl. HGT); theoretical guarantees under stochastic models; scalability with whole genomes
* Statistical models of evolution: new models of tree shape / sequence evolution; identifiability
* Deep learning to improve large-scale phylogenetic tree and network estimation
* Applications: historical linguistics, microbiome analysis, protein structure/function, tumor evolution

From phylogenomics part 2 (GDL): improve DISCO; better quartet amalgamation methods; GDL distance
correction for ASTRID/NJst; scale concatenation; networks.
From divide-and-conquer trees: a better disjoint tree merger (DTM) that allows "blending".
